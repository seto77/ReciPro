# Crystal Diffraction (衍射模拟器)

**Crystal Diffraction (衍射模拟器)** 模拟单晶 X 射线、中子和电子衍射图样。

![衍射模拟器](../../assets/cap-zh-Hans-auto/FormDiffractionSimulator.png)

窗口**左侧**为衍射图样的绘制区，**右侧**为 **模拟设置** 面板（波源、光学、强度计算、外观等）。波源与光学的组合决定采集模式（X 射线衍射、SAED、PED、CBED），右侧面板也随之重新配置。

---

## 本页与各模式页面如何分工

- **本页（枢纽页）**：汇总每个模式共有的操作（快捷键、菜单、工具栏、屏幕/探测器信息、叠加层选项卡、衍射斑点信息、探测器几何、动态压缩）。
- **各模式页面**：涵盖选中该模式时**右侧出现的每一项设置**（波长、入射束、强度计算、外观、布洛赫波设置、进动设置等），因此每个页面都是自包含的（各模式之间存在一些重叠）。

| 模式 | 内容 | 页面 |
|------|----------|------|
| **X 射线（及中子）衍射** | 单晶 X 射线 / 中子衍射图样（平行束、进动 X 射线、Back Laue） | [X 射线衍射模拟](5-x-ray-neutron-diffraction.md) |
| **SAED** | 平行束电子衍射（选区电子衍射） | [SAED 模拟](1-saed-simulation.md) |
| **PED** | 进动电子衍射 | [PED 模拟](2-ped-simulation.md) |
| **CBED** | 会聚束电子衍射 | [CBED 模拟](3-cbed-simulation.md) |

> **ALCHEMI 不是一种模式。** 与由波长和入射束的组合决定的 X 射线 / SAED / PED / CBED 不同，ALCHEMI 模拟器是从 **选项** 菜单打开的**子窗口**，故在此单独列出。

| 子窗口 | 内容 | 页面 |
|------|------|------|
| **ALCHEMI 模拟器** | 按位点分解的电离摇摆曲线（沟道增强微分析） | [ALCHEMI 模拟](4-alchemi-simulation.md) |

隐藏衍射模拟器时，其所有子窗口（衍射斑点信息、探测器几何、CBED、动态压缩、TEM 样品台模拟和 ALCHEMI 模拟器）也会一并隐藏。再次显示模拟器时，只有 CBED 窗口（在会聚模式下）会自动重新打开。<!-- 261105Cl 監査: FormElectronDiffraction_VisibleChanged (f98bc0d) -->

## 模式速查

根据 **波源** 与 **光学**（入射束）的组合，查找你需要的页面。

| 波源 | 光学 | 模式 | 页面 |
|------------|--------------------|------|------|
| 电子 | 平行束 | SAED | [SAED 模拟](1-saed-simulation.md) |
| 电子 | 进动（电子） | PED | [PED 模拟](2-ped-simulation.md) |
| 电子 | 会聚（电子） | CBED | [CBED 模拟](3-cbed-simulation.md) |
| X射线 | 平行束 | X 射线衍射 | [X 射线衍射模拟](5-x-ray-neutron-diffraction.md) |
| X射线 | 进动（X射线，ZOLZ） | 进动 X 射线（进动相机） | [X 射线衍射模拟](5-x-ray-neutron-diffraction.md) |
| X射线 | 背反射劳厄（X射线） | 背反射劳厄 | [X 射线衍射模拟](5-x-ray-neutron-diffraction.md) |
| 中子 | 平行束 | 中子衍射 | [X 射线衍射模拟的中子部分](5-x-ray-neutron-diffraction.md) |

> **Note**: 入射束（**光学**）的可选项随波长而变化。对于电子：**平行束、进动（电子）、会聚（电子）**；对于 X 射线：**平行束、进动（X射线，ZOLZ）、背反射劳厄（X射线）**；对于中子：仅 **平行束**。更改波源时，光学设置总会重置为 **平行束**。选择 **进动（电子）** 或 **会聚（电子）** 会自动将强度计算切换为 **动力学理论**；**动力学理论** 仅对电子提供（选择 X 射线或中子时会退回到 **运动学 & 激发误差**）。背反射劳厄使用白光（多色）射束。

## TEM 样品台模拟

![TEM 样品台模拟](../../assets/cap-zh-Hans-auto/FormDiffractionSimulatorHolder.png)

打开一个窗口，将衍射图样与双倾 **TEM 样品台**（**倾转 X** = 主旋转，**倾转 Y** = 次旋转）联动。设置样品台倾角会更新图样和晶体取向，可达取向可在极射赤平投影上显示（v4.914 新增）。**链接到当前方向** 以当前晶体取向作为样品台的基准（对应给定的倾转 X / 倾转 Y）；**TEM 专用设置** 给出屏幕上倾转 X 轴的方向（默认 −29°）和倾转 Y 的极性，**↻ 旋转 180°** 使晶体绕射束旋转 180°（始终绕束轴旋转，即使在主窗口中固定了轴或晶面）。在极射赤平投影上左键双击会将样品台倾角设为该点，勾选 **启用方向键** 后可用 ←/→ 逐步改变倾转 X、用 ↑/↓ 逐步改变倾转 Y（步长 0.1–2°，默认 0.2°）。方向键仅在此窗口处于活动状态时使样品台倾转。<!-- 261106Cl 作者の決定 D25 --> 窗口（随模拟器）被隐藏后再次显示时，或更改倾转 X / 倾转 Y 时，期间所做的旋转或晶体更换会被当作新的基准：当前取向被视为当前倾角下的取向，并为当前晶体重建晶带轴列表。<!-- 261105Cl 監査: FormDiffractionSimulatorHolder.cs OnVisibleChanged / numericBoxTilt_ValueChanged (54e23f0) -->

## 绘制叠加层选项卡 {#drawing-overlay-tabs}

### 通用

![通用选项卡](../../assets/cap-zh-Hans-auto/FormDiffractionSimulator.toolStripContainer1.panelMain.tabControl.tabPageGeneral.png)

设置标签的 **文字大小**，以及标签 **文字**、**样品垂足位置** 标记、**透射斑点位置** 标记和 **背景** 的颜色（两个标记都可以分别关闭）。斑点颜色在 **外观** 中设置（见各模式页面）；菊池线、德拜环和刻度线的颜色在各自的选项卡中设置。此处的设置适用于所有渲染模式。

### 菊池线

![菊池线选项卡](../../assets/cap-zh-Hans-auto/FormDiffractionSimulator.toolStripContainer1.panelMain.tabControl.tabPageKikuchi.png)

![菊池线选项卡（动力学模式）](../../assets/cap-zh-Hans-auto/FormDiffractionSimulator.toolStripContainer1.panelMain.tabControl.tabPageKikuchi-dynamical.png)

在工具栏启用菊池线时生效。

- **反射选择** : 选择由哪些反射生成菊池线。可选 **结构因子**（按 $\lvert F_{hkl}\rvert$ 排名的 **上限** *N* 个反射；1–1000，默认 100）或 **1/d 截止**（所有 1/d 低于阈值的反射；0–100 nm⁻¹，默认 10）。
- **模式** : 菊池线的绘制方式（默认 **运动学**）。组合框下方的设置随模式切换。
    - **几何** : 所有选中的线以同一固定颜色绘制。
    - **运动学** : 线的浓淡按各反射的运动学相对强度变化。
    - **动力学** : 以热漫散射为源的双束动力学过剩/亏损带轮廓，在后台线程中计算。过剩带出现在高角侧，亏损特征朝向直射束一侧；试样厚度与强度设置共用。计算期间先以几何线代替显示。动力学带仅对 **电子** 束计算；对于 X 射线和中子，菊池线以几何线绘制，并显示提示 *仅限电子束：以线显示*。<!-- 261105Cl 監査: DrawKikuchiLine / UpdateKikuchiNotice -->
- **几何 / 运动学的设置** : **菊池线颜色** 和 **线宽**。
- **动力学的设置** :

    - **标度** : 亮度压缩曲线（Linear / Log / Tanh；默认 Tanh）。均为可视化变换，并非物理相机响应。
    - **锁定亮度** : 冻结亮度归一化，例如用于比较不同取向或厚度。
    - 下方灰色注记显示源与吸收不一致的提示、绘制的带数及诊断信息（例如对 *B* = 0 的原子代用默认 *B* 因子）。

## 衍射斑点信息 {#diffraction-spot-information}

列出用布洛赫波法（动力学计算）计算的逐反射详情。用强度计算面板中的 **斑点详情** 按钮打开它。在 **仅激发误差** / **运动学** 模式下，该按钮列出当前绘制的反射及其电子势和 $P_g$、$Q_g$（没有动力学振幅）；在 CBED 模式下，表格对应 CBED 窗口中所选的厚度。对于 X 射线和中子，$S_g$、$P_g$ 和 $Q_g$ 以实际波长计算（不作折射修正），势的各列和势单位选择器被隐藏，加速电压、$m/m_0$ 和 $v/c$ 显示为“-”。<!-- 261105Cl 監査: FormDiffractionSpotInfo.cs SetTable (C 組) -->

![衍射斑点信息](../../assets/cap-zh-Hans-auto/FormDiffractionSpotInfo.png)

### 示意图与定义

示意图（左上）显示埃瓦尔德球上的矢量，并定义表中所用的量（$\hat{\mathbf{n}}$ 是垂直于样品表面的单位法向矢量，$\mathbf{k}$ 是入射波矢，$\mathbf{g}$ 是倒易点阵矢量）。

- $P_g = 2\,\hat{\mathbf{n}} \cdot (\mathbf{k} + \mathbf{g})$
- $Q_g = |\mathbf{k}|^2 - |\mathbf{k} + \mathbf{g}|^2 = -\mathbf{g} \cdot (2\mathbf{k} + \mathbf{g})$
- **偏离矢量:** $S_g = \dfrac{\sqrt{P_g^2 + 4 Q_g} - P_g}{2}$
- **评价函数:** $R = |\mathbf{g}|\, Q_g^2$ — 按反射被激发的强弱排序（越小 = 越接近埃瓦尔德球 = 激发越强；透射束 $g=0$ 的 $R=0$ 排在最前）。表按 $R$ 升序排序。

### 表格列

| 列 | 含义 |
|--------|---------|
| **R** | 评价函数 $R = \lvert\mathbf{g}\rvert\, Q_g^2$（见上；用于选择 / 排序反射） |
| **h, k, (i,) l** | 米勒指数（*i* 是冗余的六方指数，仅对六方晶体显示） |
| **d** | 晶面间距（nm） |
| **gX, gY, gZ** | 倒易点阵矢量 *g* 的分量（1/nm） |
| **\|g\|** | *g* 的模（1/nm） |
| **Vg re / Vg im** | 弹性散射的晶体势傅里叶系数 $V_g$（实部 / 虚部） |
| **V'g re / V'g im** | 热漫散射（TDS）的虚（吸收）势 $V'_g$（实部 / 虚部） |
| **Sg** | 偏离矢量 $S_g$（见上；1/nm） |
| **Pg** | 辅助量 $P_g = 2\,\hat{\mathbf{n}}\cdot(\mathbf{k}+\mathbf{g})$（见上） |
| **Qg** | 辅助量 $Q_g = -\mathbf{g}\cdot(2\mathbf{k}+\mathbf{g})$（见上） |
| **Φ re / Φ im** | 出射面上动力学衍射波的复振幅 $\Phi$（实部 / 虚部） |
| **\|Φ\|^2** | 该反射的衍射强度 $\lvert\Phi\rvert^2$ |
| **Σ\|Φ\|^2** | $\lvert\Phi\rvert^2$ 的累积和（对所有反射求和；可用作强度守恒检验） |

### 势的单位及其他控件

- **势的单位** : 在 **Vg [eV]**（静电势，eV）与 **Ug [nm⁻²]**（进入布洛赫波方程的缩放量 $U_g = (2 m_0/h^2)\, V_g$）之间切换显示的势。列标题也相应地在 *Vg / V'g* 与 *Ug / U'g* 之间变化。仅对电子显示。<!-- 261106Cl 作者の決定 C5 -->
- 表格上方显示加速电压、波长（$\lambda = 1/k_\text{vac}$）、相对论质量比 $m/m_0$、速度比 $v/c$、点阵体积、样品厚度，以及（在 CBED 模式下）会聚半角 α。厚度仅在 **动力学** 计算时显示（CBED 模式下为 CBED 窗口的厚度），半角仅在 CBED 模式下显示；否则显示为“-”。
- **注 1:** 长度单位为 **nm**，而非 Å。**注 2:** 波数单位为 **1/nm**，而非 2π/nm。
- **有效位数** : 表中显示的有效数字位数（1–16，默认 4）。**自动调整行宽** : 自动适配列宽。**复制到剪贴板** : 将表格导出为可粘贴到电子表格中的文本。**另存为 CSV** : 将同一表格（可见列）写入 CSV 文件；小数点始终为句点，因此在以逗号作小数点的区域设置下文件仍然有效。即使表格只有一行，**复制到剪贴板** 和 **另存为 CSV** 也可使用。两者都以给出条件的 `# key: value` 行开头（波源、加速电压或能量、波长、厚度、CBED 时的会聚半角、晶体、欧拉角、计算模式），列标题带有单位，例如 `d (nm)`、`Sg (nm⁻¹)`、`Qg (nm⁻²)`。<!-- 261106Cl 作者の決定 C22 -->
