# Главное окно

При запуске ReciPro появляется главное окно. Из этого окна вы выбираете кристалл, управляете его вращением и вызываете различные функции.

![Главное окно](../assets/cap-ru-auto/FormMain.png)

| Область | Расположение | Описание |
|------|----------|-------------|
| **Меню Файл** | Сверху | Операции с файлами, параметры, справка |
| **Управление вращением** | Слева | Просмотр/задание ориентации кристалла |
| **Список кристаллов** | Верхний центр | Выбор кристаллов и управление ими |
| **Сведения о кристалле** | Нижний центр | Редактирование параметров решётки, симметрии, атомов |
| **Функции** | Справа | Запуск окон моделирования/анализа |

| Удерживать <kbd>CTRL</kbd> при запуске ReciPro | Запуск с отключённым OpenGL (восстановление при проблемах с графикой; только для этого запуска, не сохраняется) |

## Базовый рабочий процесс

Если вы впервые работаете с ReciPro, выполните следующие шаги:

1. Выберите нужный кристалл в **Списке кристаллов**. Чтобы использовать файл CIF/AMC, перетащите его в **Сведения о кристалле**.
2. Если вы редактируете параметры решётки или положения атомов, нажмите **Добавить** или **Заменить**, чтобы изменения были записаны обратно в список кристаллов.
3. Задайте ориентацию кристалла в **Управлении вращением**, используя ось зоны, кристаллическую плоскость, углы Эйлера или перетаскивание мышью.
4. Откройте нужный инструмент из **Функций**. Окна расчётов для дифракции, HRTEM/STEM, EBSD и других используют текущий выбранный кристалл и его ориентацию.

## Управление ориентацией кристалла

Состояние вращения кристалла совместно используется симулятором дифракции, Просмотром структуры, Стереосетью, симулятором HRTEM/STEM, симулятором EBSD и другими окнами. Это не просто настройка отображения — оно определяет направление падающего пучка и связь координат кристалла, используемую в моделировании. Краткий видеоурок доступен на странице [Использование](appendix/a0-how-to-use.md).

### Текущая ориентация

![Текущая ориентация](../assets/cap-ru-auto/FormMain.toolStripContainer1.panel1.groupBoxCurrentDirection.png)

Показывает ориентацию кристалла. Перетаскивайте для вращения. Оси: красная = *a*, зелёная = *b*, синяя = *c*.

### Сбросить поворот
Сбрасывает к исходному состоянию: ось *c* перпендикулярна экрану, ось *b* направлена вверх.

### Ось зоны
Показывает ось зоны [*uvw*], ближайшую к нормали экрана. Кандидатами служат несократимые индексы (НОД = 1) с $|u|+|v|+|w| \le$ предела в поле max-UVW (1–100, по умолчанию 30); двойной щелчок по подписи индекса показывает или скрывает это поле.

### Углы Эйлера (Z-X-Z)
Задайте ориентацию кристалла с помощью углов Эйлера **Z–X–Z**:

- \(\Phi\): поворот вокруг оси Z
- \(\Theta\): поворот вокруг оси X
- \(\Psi\): поворот вокруг оси Z

Повороты применяются в порядке \(\Psi \to \Theta \to \Phi\). Подробнее см. [Геометрия вращения](4-rotation-geometry.md) и [Приложение A1. Система координат](appendix/a1-coordinate-system/1-orientation.md).

### Стрелки

![Стрелки](../assets/cap-ru-auto/FormMain.toolStripContainer1.panel1.groupBoxArrows.png)

Поворачивает на угол **Шаг** (по умолчанию 10°). ↺ / ↻ поворачивают вокруг нормали экрана. Установите **Animation** для непрерывного вращения; тогда **Шаг** задаёт скорость в °/с.

### Вид вдоль

![Вид вдоль](../assets/cap-ru-auto/FormMain.toolStripContainer1.panel1.groupBoxProjectAlong.png)

Выравнивает ось зоны [*uvw*] или кристаллическую плоскость (*hkl*) перпендикулярно экрану.

- **Фикс.**: если отмечено, все последующие повороты (стрелки, перетаскивание мышью) выполняются вокруг заданной оси зоны или нормали плоскости, так что это направление остаётся неподвижным. Включён может быть только один из двух флажков **Фикс.**, и его нельзя отметить, пока индекс равен 0 0 0.
- **Ось**: устанавливает введённую ось зоны \([uvw]\) перпендикулярно экрану. Если также задано **Плоскость** и ось лежит в этой плоскости ($uh+vk+wl=0$), нормаль плоскости направляется вверх на экране; в противном случае направление вверх выбирается автоматически.
- **Плоскость**: устанавливает нормаль введённой кристаллической плоскости \((hkl)\) перпендикулярно экрану. Если также задано **Ось** и она лежит в этой плоскости ($uh+vk+wl=0$), эта ось направляется вверх на экране; в противном случае направление вверх выбирается автоматически.

### Основные способы задания ориентации

| Метод | Использовать, когда | Где |
|--------|----------|-------|
| Перетаскивание мышью | Вы хотите свободно вращать, наблюдая за осями кристалла. | Панель **Текущая ориентация** |
| Кнопки со стрелками | Вам нужны небольшие повторяемые повороты. | Панель **Стрелки** |
| Ось зоны | Вы знаете направление обзора, например \([001]\) или \([110]\). | **Вид вдоль** / ввод оси зоны |
| Нормаль плоскости | Вам нужна кристаллическая плоскость \((hkl)\) перпендикулярно экрану. | **Вид вдоль** / ввод плоскости |
| Углы Эйлера | Вам нужна воспроизводимая числовая ориентация. | **Углы Эйлера (Z-X-Z)** |

См. [Геометрия вращения](4-rotation-geometry.md) и [Приложение A1. Системы координат](appendix/a1-coordinate-system/1-orientation.md) для матриц вращения и соглашений о координатах.

## Сведения о кристалле

Редактируйте параметры решётки, симметрию и атомы; перетаскивайте файлы CIF/AMC, чтобы загрузить структуру. Этот элемент управления совместно используется ReciPro, PDIndexer и CSManager, но отображаемые вкладки и функции различаются в зависимости от приложения. ReciPro показывает вкладки **Осн. инфо**, **Об атомах** и **Лит.** (вкладки EOS, Elasticity и другие предназначены для других приложений и в ReciPro не отображаются).

> **Важно**: нажмите **Добавить** или **Заменить**, чтобы сохранить изменения.

![Crystal Control](../assets/cap-ru-auto/FormMain.toolStripContainer1.splitContainer.groupBoxCrystalInformation.crystalControl.png)

Верхняя часть панели всегда показывает **Name** (название кристалла), **Формула** (химическая формула, вычисленная из списка атомов), **Z** (число формульных единиц на элементарную ячейку) и **Цвет** (цвет отображения кристалла, используемый в трёхмерном виде структуры и на кривых дифракционных профилей). Кнопки **Инфо о симметрии** и **Взаимодействие пучка** открывают окна [Сведения о симметрии](2-symmetry-information.md) и [Взаимодействие пучка](3-beam-interaction.md). Массовые и атомные доли и пересчёт на оксиды показывает пункт контекстного меню [Подробный химический состав](#chemical-composition).

### Вкладка Об атомах {#atom-tab}

| Элемент | Описание |

| X, Y, Z | Дробные координаты (0–1). Можно вводить дроби, такие как 1/2 или 2/3. |
| Occ | Заселённость (0–1). |

Щёлкните правой кнопкой мыши по строке атома и выберите **Показать эквивалентные позиции атома**, чтобы открыть небольшое окно со списком всех позиций, порождённых операциями симметрии пространственной группы; кнопка **Copy** копирует список как текст, разделённый табуляциями (например, для вставки в электронную таблицу).

**Сдвиг начала координат**: сдвигает начало отсчёта всех атомных координат. Выберите знак с помощью **+** / **−**, затем нажмите один из предустановленных векторов — (⅛ ⅛ ⅛), (¼ ¼ ¼), (0 ¼ ⅛), (¼ 0 ¼), (0 ¼ ¼), (¼ ¼ 0), (¼ −¼ 0), (¼ −¼ ¼), (0 ¼ −⅛) — или используйте **Apply custom shift** для произвольной величины.

**Смещение (B)** (фактор Дебая–Валлера / температурный фактор):

| Элемент | Описание |
|------|------|
| Notation | Использовать нотацию U или B. При переключении отображаемые значения пересчитываются ($B = 8\pi^2 U$). |
| Модель | Изотропный или анизотропный. |
| U##, β## | Для анизотропного случая введите каждую компоненту: $U_{ij}$ в Å² или в нотации B безразмерные $\beta_{ij} = 2\pi^2 a^*_i a^*_j U_{ij}$ (как B(i,j) в файлах AMCSD). |

**Фактор рассеяния**: выберите фактор рассеяния, используемый для каждого атома.

| Излучение | Источник / настройка |
|-----------|------|
| X-ray | Факторы рассеяния, включая ионную валентность (International Tables for Crystallography, Vol. C). |
| Electron | Факторы рассеяния электронов — для нейтральных атомов из Peng, Ren, Dudarev & Whelan (1996), *Acta Cryst.* **A52**, 257–276; для ионов из Peng (1998), *Acta Cryst.* **A54**, 481–485. |
| Neutron | Длины рассеяния нейтронов. Выберите **Natural isotope abundance** или **Custom isotope abundance** (произвольный изотопный состав). |

#### Подробный химический состав {#chemical-composition}

![Подробный химический состав](../assets/cap-ru-auto/FormChemicalComposition.png)

Показывает состав текущего кристалла, рассчитанный по списку атомов (число атомов каждого элемента — сумма кратность × заселённость по его позициям). Окно следует за кристаллом, выбранным в главном окне.

- Правая таблица показывает для каждого элемента **мас. %**, **ат. %** и **Число атомов (нормир.)**; левая таблица — число атомов на ячейку. Щёлкните поле нормированного столбца в левой таблице, чтобы сделать этот элемент опорным, и введите его число атомов (например, O = 24). По умолчанию опорный элемент — O (иначе первый элемент), и нормированный столбец показывает химическую формулу.
- **Оксиды**, **Галогениды** и **Сульфиды** (показываются только применимые к кристаллу) формально пересчитывают состав в компоненты, используя валентность каждого элемента (столбец **Валентность**). Валентности можно редактировать (допускаются дроби вроде 8/3). Если значение не введено, для Fe берётся 2, для остальных элементов — валентность иона, выбранного для фактора рентгеновского рассеяния, иначе — обычная степень окисления. **Σ=0** задаёт валентность, при которой суммарный заряд равен нулю, а **По умолчанию** удаляет введённые валентности. Введённые валентности хранятся в кристалле и сохраняются в XML-списках кристаллов.
- **В порядке ввода** / **По атомному номеру** переключают порядок элементов.
