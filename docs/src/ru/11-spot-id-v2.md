# Spot ID v2

**Spot ID v2** обнаруживает, аппроксимирует и индицирует дифракционные рефлексы на экспериментальном дифракционном изображении. [Spot ID v1](10-spot-id.md) (прежний TEM ID), напротив, принимает геометрию рефлексов как числовой ввод.

![Spot ID v2](../assets/cap-ru-auto/FormSpotIDV2.png)

---

## Сочетания клавиш и мыши

Список рефлексов вы создаёте непосредственно на загруженном изображении. Область изображения использует стандартную [навигацию по изображению](21-shortcuts.md) ReciPro для панорамирования/масштабирования; для редактирования рефлексов добавляются приведённые ниже комбинации.

| Сочетание | Действие |
|----------|--------|
| <kbd>F1</kbd> | Открыть эту страницу онлайн-руководства |
| Двойной щелчок левой кнопкой по изображению | Добавить рефлекс в этой точке (с подгонкой пика) |
| <kbd>CTRL</kbd> + двойной щелчок левой кнопкой | Добавить рефлекс и отметить его как прямой (000) пучок |
| Щелчок левой кнопкой по рефлексу | Выбрать ближайший рефлекс |
| <kbd>CTRL</kbd> + щелчок правой кнопкой по рефлексу | Удалить ближайший рефлекс |
| <kbd>CTRL</kbd> + клавиши со стрелками | Сместить выбранный рефлекс на один пиксель |
| Перетаскивание левой / средней кнопкой (пустая область) | Панорамировать изображение |
| Колесо мыши | Приблизить / отдалить у курсора |
| Перетаскивание правой кнопкой рамки | Приблизить выбранную область |
| Двойной щелчок правой кнопкой | Отдалить |
| Двойной щелчок по заголовку строки рефлекса (таблица) | Приблизить к этому рефлексу (×2) |

→ См. **[21. Сочетания клавиш и мыши](21-shortcuts.md)** для обзора всех окон.

## Меню «Файл»

Открытие дифракционного изображения; **Сохранить** / **Копировать** записывают отображаемое изображение как метафайл (EMF) или изображение (PNG). Изображения можно также загружать перетаскиванием. Для файла Gatan DM3/DM4, откалиброванного в нм⁻¹, излучение устанавливается на электроны, а ускоряющее напряжение и размер пикселя (нм⁻¹) считываются из файла (длина камеры в этом случае не нужна).

**Сохранить ▸ Candidate list (CSV)...** экспортирует найденные при индицировании кандидаты ориентации, а **Копировать ▸ Candidate list (TSV)** помещает ту же таблицу в буфер обмена: по одной строке на кандидат × зерно, с рангом, номером зерна, названием кристалла, углами Эйлера ZXZ (°), девятью элементами матрицы поворота, среднеквадратичной невязкой (nm⁻²), числом сопоставленных рефлексов и сопоставлениями рефлекс → (hkl). В CSV десятичный разделитель всегда точка; TSV можно сразу вставить в электронную таблицу.

## Оптика

![Оптика](../assets/cap-ru-auto/FormSpotIDV2.splitContainer1.panel1.groupBoxOptics.png)

### Источник излучения

Выберите тип излучения (рентгеновское / электронное / нейтронное) и задайте энергию или длину волны.

### Длина камеры / Размер пикселя

Длина камеры (мм) и размер пикселя детектора (мм или нм⁻¹). При загрузке файла Gatan DM, откалиброванного в нм⁻¹, размер пикселя (нм⁻¹) берётся из заголовка файла, а длина камеры не используется (пока единица — нм⁻¹, поле длины камеры недоступно). При изменении длины волны, длины камеры или единицы размера пикселя положения рефлексов (в пикселях) сохраняются, а их *d* пересчитываются с новой калибровкой.

Положение окна и калибровка (источник, энергия, длина камеры, а также единица и значение размера пикселя) сохраняются до следующего запуска; открытие файла изображения, содержащего калибровку, перезаписывает их. <!-- 261105Cl 監査: NumericBoxPixelSize_ValueChanged (8860d40)、FormMain.cs の保存・復元 (dc42de3) -->

**Показать кольца Дебая** (по умолчанию выкл.) рисует кольца Дебая всех кристаллов, выбранных в главном окне, — каждый кристалл своим цветом, если выбрано несколько, — с центром в прямом пучке и с текущей калибровкой (длина волны, длина камеры, размер пикселя); кольца рефлексов, запрещённых правилами погасания, не рисуются. **Показать направляющие окружности** (по умолчанию вкл.) рисует на картине направляющие окружности. <!-- 261106Cl 作者の決定 I10 -->

## Информация о рефлексе

![Информация о рефлексе](../assets/cap-ru-auto/FormSpotIDV2.splitContainer1.groupBoxSpot.png)

- **Найти & подогнать рефлексы**: Автоматическое обнаружение рефлексов с использованием локальных максимумов и вычитания фона.
- **Число**: Максимальное число обнаруживаемых рефлексов.
- **Ближайший сосед**: Минимальное расстояние (px), допустимое между обнаруженными рефлексами. Пики, расположенные ближе этого расстояния, объединяются, что предотвращает двойное обнаружение одного и того же рефлекса.
- **Радиус подгонки**: Радиус (px) круговой области, используемой для подгонки пика каждого рефлекса. Пиксели внутри этого круга подгоняются псевдо-фойгтовской функцией.
- **Применить ко всем**: Устанавливает радиус подгонки каждого рефлекса равным текущему значению **Радиус подгонки**.
- **Удалить / Очистить все**: Удалить выбранный рефлекс или все обнаруженные рефлексы.
- **Сохр.** / **Копир.**: Сохранить таблицу рефлексов в файл CSV или скопировать её в буфер обмена как текст, разделённый табуляциями. Обе операции работают даже с одним рефлексом. В CSV десятичным разделителем всегда служит точка; файл можно прочитать обратно через **Файл ▸ Загрузить** (сначала должно быть загружено изображение; рефлексы добавляются к уже имеющимся в списке). <!-- 261105Cl 監査: GetSpotListText / readCSV (7f65908) -->
- **Подогнать все**: Заново подогнать положения и интенсивности всех обнаруженных рефлексов.
- **Символы** / **Номера**: Показывать на наблюдаемых рефлексах символы-маркеры / номера (по умолчанию оба включены).
- **Глоб. подг.**: Выполнить глобальную подгонку положений всех рефлексов одновременно (экспериментальная функция).
- **Donut**: Применить вычитание фона в форме кольца (экспериментальная функция); соседнее поле задаёт ширину (px) кольца вокруг каждого рефлекса, среднее значение в котором вычитается как локальный фон.
- **Детали рефлекса**: Если флажок установлен, открывается окно с подробными сведениями о текущем выбранном рефлексе.
- **Детали функции** (при открытии окна выключено): Показать рисунок двумерной псевдо-фойгтовской функции и её параметров (x_0, y_0, H1, H2, θ, η, A, B_0, B_x, B_y), используемых в таблице рефлексов.

![Детали рефлекса](../assets/cap-ru-auto/FormSpotIDv2Details.png)

## Index

![Index](../assets/cap-ru-auto/FormSpotIDV2.splitContainer1.groupBoxIndex.png)

- **Идентифицировать рефлексы**: Запускает алгоритм индицирования для поиска наиболее подходящего кристалла и оси зоны. Во время работы на её месте появляется кнопка **Стоп**, прерывающая поиск. Нужны загруженное изображение, не менее двух рефлексов и хотя бы один кристалл, выбранный в списке кристаллов главного окна; иначе сообщение указывает, чего не хватает. Пока открыт Spot ID v2, список кристаллов главного окна допускает множественный выбор. <!-- 261105Cl 監査: buttonIdentifySpots_Click (494ef52)、FormMain.cs の複数選択 (4020433) -->
- **Допустимая ошибка**: Относительный допуск по межплоскостному расстоянию в % (0,1–10, по умолчанию 2). Допуск по углу между рефлексами выводится из него как asin(допуск)/2.
- **Игнорировать запрещённые рефлексы** (по умолчанию выкл.; только для электронной дифракции): Если флажок установлен, все систематически погашенные рефлексы, включая запрещённые винтовыми осями и плоскостями скользящего отражения, исключаются из кандидатных рефлексов. Если флажок снят, исключаются только погасания, обусловленные центрировкой решётки (I, F, A, B, C, R), поэтому запрещённые винтовыми осями / плоскостями скольжения рефлексы, которые могут появиться из-за многократной дифракции, остаются кандидатами. Для рентгеновских лучей и нейтронов все погашенные рефлексы исключаются всегда (кинематическое рассмотрение); флажок тогда показан отмеченным и недоступным и возвращается в прежнее состояние при обратном переключении источника на электроны. <!-- 261106Cl 作者の決定 I4 -->
- **Одно зерно** / **Несколько зёрен**: Поиск одной ориентации (монокристалл) или нескольких ориентаций (поликристаллическая / многозёренная область). Для нескольких зёрен параметр **Макс. число зёрен** задаёт верхний предел числа искомых зёрен.
- **Показать ось зоны** / **Показать символ** / **Показать подпись**: Наложить ось зоны и символы / подписи индексов рассчитанных рефлексов.
- **Уточнить толщину & направление (только для SAED)**: Работает только при источнике **Электроны** (иначе об этом сообщает строка состояния и ничего не вычисляется). <!-- 261105Cl 監査: ButtonRefineThicknessAndDirection_Click / Bethe_CbedCompleted (ed018ca) --> Уточнить толщину образца (nm) и направление пучка для выбранного зерна, сопоставляя наблюдаемые интенсивности рефлексов с динамическими расчётами (метод блоховских волн). **Дифрагированные волны** (1–2048, по умолчанию 400) — число пучков, а **Диапазон углов поиска** (mrad, 1–10, по умолчанию 2) — угловой полудиапазон перебираемых направлений падения. Уточнение нельзя прервать (кнопка **Стоп** относится только к **Идентифицировать рефлексы**); до его окончания окно недоступно. Перебираются толщины 50–549 nm (шаг 1 nm) и направления падения на квадратной сетке вокруг текущей ориентации зерна (шаг = 1/15 диапазона поиска), и выбирается пара, минимизирующая Σ (I<sub>obs</sub> − a·I<sub>calc</sub>)² по проиндицированным рефлексам (a — наилучший масштабный множитель). Наилучшая толщина передаётся в симулятор дифракции, а ориентация зерна (применяемая и в главном окне, если кристалл там не был сменён во время расчёта) наклоняется так, чтобы наилучшее направление стало направлением пучка; поворот в плоскости сохраняется. Результат (толщина, наклон в mrad, ось зоны, невязка) выводится в строке состояния. Если наилучшее направление лежит на краю диапазона поиска, строка состояния сообщает об этом, поскольку оптимум может лежать за его пределами: нажмите кнопку ещё раз (поиск тогда центрируется на уточнённой ориентации) или расширьте диапазон. <!-- 261105Cl 方位の精密化の実装に合わせて追記 (根拠: FormSpotIDV2.cs: ButtonRefineThicknessAndDirection_Click / Bethe_CbedCompleted) -->
- **Результаты**: Наилучшие совпадения отображаются с именем кристалла, осью зоны [uvw] и индексами отдельных рефлексов (hkl). Выбор строки отдельного зерна также выбирает его кристалл в главном окне и задаёт эту ориентацию. <!-- 261105Cl 監査: bindingSourceGrains_CurrentChanged (I11) -->
