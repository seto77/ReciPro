# Spot ID v1

**Spot ID v1**（旧 **TEM ID**）は、1〜3 枚の回折パターンについて数値入力したスポットジオメトリから、候補となる晶帯軸を検索します。画像からのスポット検出・フィッティング・指数付けは [Spot ID v2](11-spot-id-v2.md) で行います。

## スポットジオメトリからの晶帯軸検索（旧 TEM ID）

読み込む画像がない場合でも、制限視野電子回折 (SAED) パターンのジオメトリを手入力して候補晶帯軸を検索できます。TEM観察条件とスポットジオメトリを入力し、**晶帯軸を検索** ボタン（複数の写真を組み合わせる場合は **二枚の写真から晶帯軸を検索** / **三枚の写真から晶帯軸を検索**）で候補となる結晶方位を検索します。

### TEM条件

<!-- 261105Cl コードから起こした修正。別担当がコードと再照合済み (誤りは訂正) (根拠: FormSpotIDv1.Designer.cs: numericBoxAccVol / numericBoxCamaraLength / textBoxWaveLength) -->
**加速電圧**（kV、既定 200）と **カメラ長**（mm、既定 1000）を入力します。**波長**（nm）は加速電圧から計算され、読み取り専用で表示されます。

### 写真1・2・3

回折スポットのジオメトリを入力します。

- 検出器上のスポット間距離を入力する場合は **mm** ボックスを使用。
- *d* 値がわかっている場合は **Å** または **nm⁻¹** 単位で入力。

**三辺** : 透過スポットを一頂点とする三角形の三辺の長さを入力。

**二辺狭角** : 透過スポットを含む二辺の長さと、その間の角度を入力。

<!-- 261105Cl コードから起こした修正。別担当がコードと再照合済み (誤りは訂正) (根拠: FormSpotIDv1.cs: textBox_TextChanged / buttonSearch_Click / buttonSearchAll_Click / checkBoxEquivalent*_CheckedChanged、FormSpotIDv1.ja.resx の ToolTip) -->
- 許容誤差（**±** の欄） : 各辺の長さは %（0〜50、既定 5）、θ は度（0〜30、既定 3）で指定します。入力しない側の値（三辺モードでは θ、二辺狭角モードでは l3）は計算して表示され、入力欄の横に得られたパターンの模式図が描かれます。
- **ホルダー条件** : その写真を撮ったときのゴニオメータホルダーの **Tilt 1** / **Tilt 2**（°）と、それぞれの許容誤差（0〜10°、既定 3°）。写真どうしのホルダー設定の間の角度が計算して表示されます。
- **写真2** / **写真3** : 2 枚目・3 枚目の写真を有効にします。写真の間にあるチェックボックスは、2 枚の写真の l1（または l2）を同じ反射とみなし、その長さをコピーします。
- 写真ごとの **晶帯軸を検索** はその 1 枚だけで、**二枚の写真から晶帯軸を検索** / **三枚の写真から晶帯軸を検索** は有効なすべての写真とそれらのホルダー傾斜角の関係を満たす組み合わせを検索します。検索対象はメインウィンドウのリストで選択したすべての結晶です（Spot ID v1 を開いている間はリストの複数選択が可能になります）。候補が 1000 件を超えると一覧は出ず、条件を絞るよう求められます。それ以外は結果ウィンドウが開き、行をダブルクリックするとその結晶を選択してその方位へ回転します。
