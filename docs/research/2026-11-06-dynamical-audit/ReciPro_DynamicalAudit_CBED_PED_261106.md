# CBED・PED・Bloch 波コア監査 (261106Ch)

## 結論

現行の行列組立てと伝搬は、平行な境界を持つ完全結晶、前方波、局所的な吸収ポテンシャルという近似の中で整合している。ただし「式が正しい」だけでは物理的に正しい出力にはならない。今回、**PED と平行回折を切り替えたときに以前の条件の固有解を使う不具合**と、**表面変更を固有解キャッシュが見落とす不具合**を実際の Si 計算で再現し、修正した。また、**重なった CBED 円板の表示は物理的な干渉和にも非干渉和にもなっていない**ことをコードで確認した。

Surface・模型のキャッシュ失効漏れは、既存 `Crystallography_計算手法の下書き_261105/ja/implementation-questions.md` **A7** に疑義が記録されていた。本調査はその疑義を再現・修正したもので、最初の発見と主張しない。PED → 別条件の平行回折 → PED の具体的な条件混入は、今回追加した再現である。

高速化の新規性を過大に扱わない。既存の技術基準にある全厚さ一括伝搬、U の streaming、MKL の内側 1 thread、Hermitian 近似の却下、FFT-Krylov の既存研究は既知事項である。今回の変更は正しさの修正であり、速度向上は主張しない。

## 2. 物理モデルの確認

### 2.1 行列・境界・吸収

ReciPro は `P_g = 2 n·(k0+g)`、`Q_g = |k0|² - |k0+g|²` として、

`A_gh = (U_(g-h) + i U'_(g-h) + δ_gh Q_g) / P_g`

を column-major で組む。**分母が行 g に付く現行実装は正しい**。無吸収の場合、通常の Euclidean norm ではなく、`Σ_g P_g |ψ_g|² / P_0` が保存量となる。既に 2026-08-29 に直した列割り退行を再発見扱いしていない。固有値伝搬 `C exp(2πi γt) C⁻¹ ψ0` と行列指数伝搬は同じ有限次元問題を解く。

native `_CBEDSolver_Eigen` は LU solve で境界係数を作り、全厚さの位相を行列積で返す。`_CBEDSolver_MtxExp` は等間隔厚さの recurrence であり、非等間隔を EVD へ切り替える現行防御は必要。吸収を含む非 Hermitian 行列を、無条件に self-adjoint solver に置き換えてはならない。既存の重元素で 1–4 % 誤差という拒否記録と整合する。

表示の `|ψ_g|²` と表面を通る流束 `P_g |ψ_g|²/P_0` は別の量である。傾斜表面の絶対電子数を出力するなら、入射電流・検出器の面積/Jacobian と合わせて定義する必要がある。今回、すべての表示強度に機械的に P 重みを掛ける変更はしていない。

### 2.2 PED

方位角 `2πk/step` に沿う円錐照射を解き、**振幅ではなく強度を方位平均する**現行方式は、時間的に走査する PED の基本モデルに合う。Vincent & Midgley (1994) のローカル PDF pp.1–2, 6–8, 11 は、Bragg 条件を通る積分と、積分しても残る系統的な動力学効果を区別している。「PED なら運動学的」という扱いは不適切。

一方、既定 step=36 が全試料・厚さ・歳差角で収束する保証はない。角度数は `M, 2M, 4M` と増やし、重要な反射の積分強度の収束を確認すべきである。弱い反射は相対誤差だけでなく入射強度基準の絶対誤差も見る。歳差角ゼロで平行回折の強度へ戻る極限は今回追加した回帰テストで確認した。

### 2.3 CBED

各入射方向に対し、基準方向で選んだ同一の有限ビーム集合を使う。ポテンシャルの共有には有利だが、大きい収束角で必要なビームが基準集合から漏れる可能性がある。**N の増加と収束角周縁での収束は独立に見る必要がある**。既存のビーム選択研究が扱っている候補半径と N の混同も引き継がれる。

CBED の現在の出力は、各 g の入射角依存の複素振幅である。実測のエネルギーフィルタなしの CBED 全体については、TDS、プラズモン、部分コヒーレンス、検出器応答をすべて含むモデルではない。

## 3. 確定した不具合と実装

### 3.1 PED 固有解の条件混入

旧 `GetPrecessionElectronDiffraction` は、他のモードも書き換える `MaxNumOfBloch` / `AccVoltage` / `BaseRotation` を、PED 固有解が作られた条件として使っていた。

再現手順:

1. Si、N=32、200 kV、傾き 0.5°、厚さ 35 nm、歳差角 15 mrad、4 方位で PED を計算する。
2. 同じ `BetheMethod` で通常の平行回折を、方位・電圧・N のいずれかを変えて計算する。
3. その新しい条件で PED を計算する。

共有フィールドは新条件、PED 固有解は旧条件なので、旧コードでは古い固有解を再利用した。反射集合の本数だけでも次の誤りを確認した。

| 変更 | 新しいインスタンスの反射数 | 旧コードの再利用結果 |
|---|---:|---:|
| 方位 | 76 | 63 |
| 電圧 200 → 120 kV | 53 | 63 |
| N=32 → 48 | 85 | 63 |

2026-11-05 の `eigenBeams` 修正は「他モード → 平行回折」の並び替えを防いだが、この逆方向は防がなかった。

### 3.2 表面変更

同じ Si・N=32・200 kV・35 nm で、Surface の成分を同じオブジェクト上で約 23° 傾けると、旧コードの透過波強度は更新されなかった。

| モード | 旧キャッシュの I000 | 新しいインスタンスの I000 |
|---|---:|---:|
| 平行回折 | 0.235955 | 0.296527 |
| PED (15 mrad, 4 方位) | 0.381274 | 0.389105 |

差は丸め誤差ではない。表面は P と屈折 k0 の物理的な入力であり、固有解の条件に含める必要がある。

### 3.3 修正方法

`BetheMethod.cs` に `DiffractionEigenSettings` を追加し、平行回折と PED がそれぞれ、**固有解を実際に作った条件**を保存する。保存対象は N、電圧、方位の 9 成分、表面の 3 成分、イオン模型、吸収模型、ビーム候補倍率、境界同点の扱い。可変オブジェクト参照ではなく値を保存する。

通常回折では初回・電圧・散乱因子模型の変化時に U0 を読む前に `uDictionary` を破棄する。U は hkl・電圧・模型の関数なので、方位・表面・N だけを変えたときは従来の U cache の利得を保つ。PED は既存の冒頭 Clear を保つ。再構築開始時に旧 snapshot を無効化し、分解成功後だけ新 snapshot を公開する。厚さだけの変更で固有解を再利用する従来の高速な経路は維持する。公開 `ClearUCache()` は依存する両方の固有解 snapshot も無効化するように強めた。旧条件式はコメントとして残し、変更箇所には `261106Ch` を付けた。

## 4. 未修正の重要な適用域: 重なった CBED 円板

コードで確定した事実:

- `FormDiffractionSimulatorCBED.cs:setDisks` は、ディスク毎に `|Amplitude|²` を `PseudoBitmap` に変換する。
- 有効画素の alpha は 255。
- `FormDiffractionSimulator.cs` の「CBED の重ね合わせ」(調査時 769–776 行) は、各 Bitmap を `Graphics.DrawImage` で順次描く。

従って重複部は後の円板が前の円板を覆い、**局所 CBED の複素振幅和でも、PACBED の強度和でもない**。非重複ディスク内の動力学計算と、この表示上の問題は分けるべきである。現行図を大収束角の定量 CBED/PACBED として使うのは不適切。

py4DSTEM の `generate_CBED` は重複時の非干渉加算を明記して PACBED と位置付けている。[固定版のソース](https://github.com/py4dstem/py4DSTEM/blob/62c042eedd71ebcb7c52ecb5294182df132f9b5d/py4DSTEM/process/diffraction/crystal_bloch.py)

改修には、共通検出器格子への座標写像、数値強度の加算、表示スケールの後掛けが必要。局所 CBED ならさらに入射 probe の位相と位置、収差、境界での位相規約を含む複素振幅の合成が要る。表示ビットマップの単純加算では新しい物理出力にならないため、今回のキャッシュ修正と一緒に場当たり的には入れていない。

[`core/solver.py`](https://github.com/Differentiable-Electron-Crystallography/diffBloch/blob/12913566c7598f975b0529d0b2f11bc862dbffbc/src/diffBloch/core/solver.py) は、微分用に matrix exponential、評価用に Hermitian eigen を区別する。縮退した固有ベクトルの微分が不安定という設計理由は ReciPro の将来の refinement に有用。

ただし eigen 側の obliquity 補正は固有ベクトルの対角成分だけを変え、その共役転置で入射係数を作る。**この式を独立した正解としては採用しない**。2×2 の代数的なチェックでは、`A=[[0.1,0.3],[0.3,-0.2]]`, `mii=(1,0.95)`, `ψ0=(1,0)` に対し t=0 の非入射成分が 0.0235375576579 残る。これは当該数行の式を NumPy で再現したもので、パッケージ全体や標準入力経路の実行試験ではない。物理的な境界条件を共通基準にして照合する必要性を示す注意点として扱う。

### 5.4 Mendis (2025) の physical optics Bloch

位相格子と自由伝搬を分け、固定試料に対する繰り返し照射の計算を O(N²)/slice にする案。共有できるポテンシャルが支配する多数の入射方向には有望。[原論文](https://journals.iucr.org/a/issues/2025/02/00/tw5012/index.html)

しかし ReciPro の P_g の方向依存・吸収・HOLZ と同一ではなく、分割幅の収束も別に必要。論文自身の Si PED 比較にも multislice との差が残り、大角入射と HOLZ が議論される。単に「O(N³) が O(N²) になる」として現行 EVD を置き換えるのは不十分。

### 5.5 2026 年の連続回転 3D ED

Cabaj et al. (2026-09-01 の preprint) は abTEM ベースで Bloch/multislice の連続回転パイプラインを比較し、方位・厚さ・エネルギーと数値収束を扱う。任意方位の多層法との照合条件を作る資料として適する。掲載論文として確定した扱いはしない。[本文](https://arxiv.org/html/2609.01378v1)

## 6. 高速化と新しい出力の優先順位

| 優先度 | 案 | 実装前に満たす条件 |
|---|---|---|
| 高 | PED の角度収束を数値出力する。M→2M で既存点を再利用し、新しい方位だけを計算 | 不足した反射はゼロという打切りも含めて、N と角度の収束を分離。固定した上限・許容誤差で停止 |
| 高 | 正式な PACBED 合成と、共通検出器座標の数値 export | 非重複極限、全強度、格子/画素の拡大での収束。表示上の上書きを物理計算と区別 |
| 中 | PED の逆行列保存を必要な α 列の保存へ置換 | 公開 `EigenVectorsInversePED` の互換方針を先に決め、thin/thick・吸収・非中心対称で比較。大量方位の memory は測る |
| 中 | 厚さ感度 `dI_g/dt`、方位感度、低次構造因子の感度を出す | 解析式と中心差分で照合、縮退に強い propagator の微分。厚さ/組成/DW の識別性を同時評価 |
| 中 | 3D ED rocking curve と露光角幅で積分した強度の export | PED と連続回転の幾何を分け、実験の露光幅・mosaicity・相対scaleを明示 |
| 研究 | 固定ビーム集合の split propagator、行列指数の作用/Krylov | 既存 FKP 研究を継承。吸収・HOLZ・全前方 cutoff と slice収束を揃え、BDN で wall/memory を比較 |
| 研究 | QCBED で低次 U_g、占有率、熱/静的 DW、電子密度差を扱う | Lin2025 のように条件の異なるパターンと独立構造情報を使い、同時に自由化しすぎない |

PED の現在の固有ベクトルと逆行列の保存だけで、おおよそ `32×step×N² bytes` を使う。N=400、step=360 なら約 1.72 GiB。α だけを保存すれば逆行列側の大部分を削減できるが、これは計算量 O(N³) 全体が消えることを意味しない。今回の root 全体監査で検討した STEM の all-slice 経路とは別の候補である。

厚さ感度は、伝搬内部では `dψ/dt = 2πi Aψ`、`dI_g/dt = 2 Re(ψ_g* dψ_g/dt)` を利用できる。ただし外部に渡す複素波動関数には既存の出射面位相も含まれるため、API の「どの ψ か」を先に固定する。

Lin et al. (2025) のローカル PDF pp.2–3, 9–10 は、平均周期ポテンシャル (CPA)、低次構造因子、吸収、DW と規則度を組み合わせた QCBED を扱う。ReciPro の IAM をそのまま結合電子密度の検出に使うことはできず、低次 U_g の外部入力や DFT potential との比較を用意するのが拡張の筋になる。[公開原論文](https://doi.org/10.1038/s41467-025-60966-0)

この有限条件では、厚さ 100 nm の角度離散化の差が、ビーム数倍増の差より大きかった。厚膜の積分に既定 36 方位を無条件に十分とする根拠はない。ただし M=36 自体はこの診断で計算しておらず、M=64 の収束も認定していない。ビーム集合も方位に応じて選び直されるので、角度数の差にはその打切りの標本化も含まれる。

#### 角度 128/256 への追跡

100 nm の大きな差を受け、結晶・N・厚さ・歳差角は変えず、角度数だけ 128/256 へ延長した。初回結果を見た後の明示的な追跡であり、独立に事前登録された検証とは呼ばない。プログラムと README を更新し、出力は **`tools/PedConvergenceCheck/results/261106_refined`** に分けて元データも保存した。初回と共通の 8,362 反射値は最大絶対差 3.24×10⁻¹⁵ で再現した。

M=256 で固定した N=64→128 の相対 L2 差は、Si の20/100 nmで **0.5521/1.0558 %**、GaAs の20/100 nmで **2.0617/2.9195 %**。この段階では N を倍にする影響の方が直近の角度差より大きい。20 nm の小さな角度差は一部で単調減少せず、方位ごとの有限ビーム集合の選択も含むため、滑らかな積分関数だけの誤差次数は仮定しない。

### 7.2 残る検証

1. 非重複 CBED の Si [001] と非中心対称 GaAs、200 kV、薄膜/厚膜について N を段階的に増やし、中心と収束円周の画素を別々に比較する。
2. 表面 20° 傾斜・無吸収で、P 重み流束と t=0 の境界を検証する。既存 `tools/BetheDivCheck` を使い、既知の正しい検査を重複実装しない。
3. PED は同一の有限 beam model で M=36,72,144,288 の反射別積分強度を比較する。36 の採用を自動的な正解としない。
4. 外部ソフトとはまず弾性・無吸収、同じ potential・単位・hkl・beam set・表面・厚さを揃える。その後に、それぞれの吸収と熱散乱模型を戻す。
5. 性能の比較は数値的な許容誤差を固定してから BenchmarkDotNet、Idle、控えめな thread で 1 本ずつ行う。異なる切捨てや異なる物理模型を高速化の成績に混ぜない。

この監査の完了は「全物理の厳密性を証明した」という意味ではない。確定した再利用不具合は修正と回帰試験まで完了し、未検証の近似・新出力は採用条件を明示して分けた。
